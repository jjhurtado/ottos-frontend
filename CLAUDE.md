# Ottos frontend · index for agents

This project uses the `a-*` team skills. Before any task, apply `a-team-conventions`.
- Settings and project rules: `docs/team/SETTINGS.md` in repository `ottos` (production orders, languages, merges).
- Shared documents: repository `ottos`, under `docs/` (UI and canvases in `docs/ui/README.md`).
- Technology reference: `docs/team/tech/` in repository `ottos` (`dart-flutter.md`).
- This repository: [README.md](README.md) (setup, environments, security, releases), [STANDARDS.md](STANDARDS.md),
  [CHANGELOG.md](CHANGELOG.md), [roadmap.md](roadmap.md), the package READMEs.
- New features are discussed with the user before they are implemented (design, technical details and doubts).
- Other sessions: backend (`ottos`, owns the API contract `docs/api/openapi.yaml`) and infrastructure (Railway,
  staging, production). Their code and configuration are not changed from here.
